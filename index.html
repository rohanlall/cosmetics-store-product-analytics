How shoppers behave in an online cosmetics store

This dashboard analyzes real events (product views, add-to-cart, remove-from-cart and purchases) from a mid-size online cosmetics store, using the public Kaggle dataset eCommerce Events History in Cosmetics Shop. The raw events were loaded into DuckDB and analyzed with SQL (analysis.py).

Source: Kaggle (mkechinov)Stack: Python · DuckDB · SQL · Chart.js
